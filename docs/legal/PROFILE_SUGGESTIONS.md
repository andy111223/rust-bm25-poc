# Propozycje uzupełnienia profilu

Agent nie zmienia samodzielnie deklaracji autora w APP_PROFILE.md.

- Doprecyzować w APP_PROFILE.md planowany sposób udostępniania: źródła, gotowy program, użytek wewnętrzny lub integracja, wraz z przewidywanymi odbiorcami.
- Uzupełnić profil o rozróżnienie między syntetycznymi danymi testowymi a materiałami rzeczywiście przekazywanymi agentom; źródła nie potwierdzają zakresu rzeczywistej wysyłki.
- Po wykonaniu odrębnej weryfikacji odnotować wersję kodu i wynik testów wykluczania plików, bez przedstawiania ich jako gwarancji usunięcia wszystkich danych poufnych.
